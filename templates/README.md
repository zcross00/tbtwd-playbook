# Templates

| Template | Use for |
|----------|---------|
| [PROCESS.md](PROCESS.md) | A project's own process file: roles, areas, labels, CI tier, differences from the playbook |
| [milestone.md](milestone.md) | A milestone description, ending in its acceptance test |
| [issue.md](issue.md) | A work issue: asks, Check line, estimate |
| [decision.md](decision.md) | A decision issue: question, options, recommendation, the owner's words |
| [GOALS.md](GOALS.md) | The owner's goals (feeds VISION.md) |
| [DESIGN.md](DESIGN.md) | A system's design spec in `docs/design/` |
| [FEATURES.md](FEATURES.md) | Optional catalog of what's built, by goal |
| [github/](github/) | PR template, issue forms, `playbook-lint` workflow |

In v2 the backlog and drift log are issues (`parked`, `deferred gate`), not files; the old BACKLOG.md and DRIFT.md templates are in [archive/v1/templates/](../archive/v1/templates/).
